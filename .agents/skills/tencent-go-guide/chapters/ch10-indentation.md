# 第 10 章: 缩进风格

## Core Idea
换行后的续行不得与缩进代码块对齐——否则一眼分不清哪段是 if 体、哪段是条件。

## Frameworks Introduced
- **对齐避让**: 当换行符会使续行与缩进代码块对齐时，避免换行（如把长条件整体放进一行，或改写条件）。续行与 if 体内代码同列 = 缩进混乱。
- **空行分隔**: 必须换行时，**故意留一个空行**把换行的条件与缩进的代码块分开。

## Anti-patterns
- **续行与函数体对齐**: `if a && b &&\n c && d {` 中 `c`、`d` 与 if 体内 `log.Info` 同级缩进，无法区分。

## Key Takeaways
1. 长条件优先不换行（一行能放下就一行）。
2. 必须换行时续行缩进一档 + 空行分隔条件与函数体。
