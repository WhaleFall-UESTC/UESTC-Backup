# Glossary — 腾讯 Go 语言编程指南

- **any** — Go 1.18 引入的 `interface{}` 别名；新代码中用 any 替代 interface{} (Ch 7)
- **裸返回 (naked return)** — 命名返回值后不带参数的 return；仅小函数可接受 (Ch 3)
- **cobra** — 子命令式 CLI 推荐库；命令函数用 cmd.Context() 取上下文 (Ch 23)
- **一致性** — 同一问题在包内只用一种解法；与旧习惯冲突时以规范为准 (Ch 1)
- **点导入 (import .)** — 把导出标识符无条件引入当前包；任何包都不建议使用 (Ch 5)
- **哨兵值 (sentinel error)** — 无参数全局错误值，调用方 `==` 或 `errors.Is` 比较 (Ch 6)
- **错误链 (error chain)** — 每层 %w 包装在链前端加条目，Unwrap 从最新到最旧遍历 (Ch 6)
- **数据驱动陷阱** — 表行携带环境枚举、循环内 switch 初始化；应按环境拆分测试函数 (Ch 25)
- **functional options** — `type Opt func(*opts)` 闭包模式；参数可选/可扩展/可失败时首选 (Ch 9)
- **Godoc** — Go 文档工具；段落空行分隔、缩进两空格逐字排版、可运行 Example (Ch 4)
- **goroutine 泄漏** — 阻塞在 channel 收发的 goroutine 不被 GC 回收；必须明确退出时机 (Ch 15)
- **Guard clause (卫语句)** — `if err != nil { return err }` 顺序排列，压平嵌套 ≤4 层 (Ch 6, Ch 9)
- **类型别名 (type T1 = T2)** — 引用现有类型不定义新类型；主要用于包迁移，很少见 (Ch 21)
- **类型定义 (type T1 T2)** — 定义全新类型（独立方法集） (Ch 21)
- **接口指针** — 指向接口的指针无用处；接口本身按值传递 (Ch 7)
- **可维护性** — 结构化 API、功能导向、无耦合、测试完备、不隐藏细节 (Ch 1)
- **Must 函数** — `MustXxx` 失败即 log.Fatal 的辅助函数；仅限启动早期/包级初始化 (Ch 14)
- **表驱动测试** — 多用例共享逻辑的测试组织方式；一行一用例、行内无逻辑分支 (Ch 25)
- **逻辑清晰** — 四原则之首；靠命名、注释、代码组织实现 (Ch 1)
- **最少依赖原则** — 基础结构体 → 标准库 → 第三方/自研，逐级降级 (Ch 1)
- **差一错误 (Off-By-One)** — `Intn(100) <= 80` 得 81% 概率；区间边界运算符要数清 (Ch 20)
- **编译期接口验证** — `var _ IType = (*impl)(nil)`（指针类）或 `impl{}`（结构体） (Ch 7)
- **嵌套深度** — 函数嵌套 ≤4 层；超出用卫语句压平 (Ch 9)
- **冗余 break** — Go switch 自动中断；case 末尾裸 break 是 C 风格残留，删除 (Ch 17)
- **缩进混乱** — 换行续行与缩进块对齐导致无法区分；避免换行或空行分隔 (Ch 10, Ch 11)
- **同包测试 / _test 包** — `abc_test.go` 可测未导出；集成/循环依赖用 `package x_test` (Ch 25)
- **同步函数优先** — 默认同步；goroutine 生命周期由调用方决定，上线后难删除 (Ch 9, Ch 15)
- **跳值陷阱 (循环变量捕获)** — go<1.22 循环变量单变量逐次赋值；闭包/取址需复制 `i := i` (Ch 11)
- **t.Helper** — 标记辅助函数，使失败归属调用处行号；不产生失败的辅助函数不加 (Ch 25)
- **t.Fatal 安全性** — 只能在测试 goroutine 调用；goroutine 内用 t.Errorf + return (Ch 24)
- **线程安全随机数** — 全局 rand 有锁竞争；高频用 rand.New 自建 + 互斥锁封装 (Ch 20)
- **UTF-8 前缀格式** — 汉字三字节（1110xxxx 10xxxxxx ×2）；len/下标是字节层次 (Ch 19)
- **Yoda 条件** — 常量在等号左侧的反模式；变量放左侧 (Ch 11)
- **ctx 第一参数** — context.Context 永远是函数第一个参数；不进结构体、不自定义类型 (Ch 22)
- **%w 位置** — 放错误串末尾 `[...]: %w`，使错误文本顺序与链顺序一致 (Ch 6)
- **零值字段省略** — Options 结构体省略零值字段突出真正配置；表驱动测试除外 (Ch 8)
