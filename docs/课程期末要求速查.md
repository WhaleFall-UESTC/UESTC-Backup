## 硬性规则（红线）

1. **语言白名单**：C/C++/C#/Java/Go。界面可用脚本语言；**后台逻辑用脚本语言 → 基础分只记 10**。
2. **第三方库减半**：扩展功能用第三方库/程序/代码"直接"实现 → **该项扩展分减半**。Huffman/LZ77/打包格式必须自研（指导书提供算法讲义）。
3. **OS 任选**（Linux/Windows/macOS，无评分差异）。
4. 考勤 ≥ 8/10 次才有成绩。

## 测试要求（课件 3 末页）

- 报告中 **≥15 个测试用例**、**≥2 种测试类型**（单元/集成/性能/稳定性等）。
- （推荐）gtest 白盒单元测试，测试代码留在源码中。
- （推荐）使用 valgrind / gprof / perf 并在报告中体现。

## 评分公式

```
起评分 = 基础 40 + 扩展分（≤110）
完成分 = 需求 10 + 设计 20 + 测试 20 + AI证书 10 + 源码质量 10 + 答辩 10 + 演示 20（=100）
小组得分 = 完成分 × 起评分 / 100
组长得分 = 小组得分；组员得分 = 小组得分 − 5（均 ≤100）
```
